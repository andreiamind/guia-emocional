🔮 Oráculo da Intuição

O Oráculo da Intuição é uma aplicação web minimalista e introspectiva, desenhada para ajudar utilizadores a sintonizarem-se com as suas emoções e a praticarem o registo reflexivo (journaling).

Este projeto foi construído para ser leve, rápido e totalmente funcional como uma PWA (Progressive Web App), permitindo que seja instalado no ecrã principal do teu telemóvel como se fosse uma aplicação nativa.

✨ Funcionalidades

Sintonização Emocional: Seleção de estados de espírito com prompts (perguntas) gerados aleatoriamente para estimular a reflexão.

Diário Intuitivo: Espaço para escrita livre focado na resposta aos desafios do Oráculo.

Histórico Local: Os teus registos são guardados de forma segura no teu próprio dispositivo (localStorage).

Insights: Visualização de padrões emocionais e palavras recorrentes através de um painel estatístico simples.

Design Adaptativo: Interface moderna, otimizada para dispositivos móveis e desktop.

🚀 Tecnologias Utilizadas

React 18: Biblioteca principal para a interface.

Tailwind CSS: Estilização responsiva e moderna.

Lucide React: Biblioteca de ícones elegantes.

JavaScript (ES Modules): Estrutura modular sem necessidade de build complexo.

📦 Como Instalar (Deploy)

Este projeto foi desenhado para ser hospedado em serviços de alojamento estático como a Vercel, Netlify ou GitHub Pages.

Faz o Fork ou Download deste repositório.

Certifica-te de que o ficheiro principal se chama index.html.

Conecta o repositório à tua plataforma de deploy favorita.

No telemóvel, acede ao link gerado e seleciona "Adicionar ao Ecrã Principal" para uma experiência de app completa.

🔒 Privacidade

Todos os dados inseridos na aplicação são armazenados localmente no navegador do utilizador. Nenhuma informação é enviada para servidores externos, garantindo total privacidade das tuas reflexões.
